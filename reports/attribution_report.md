# 績效歸因（Task 6d）

把 Task 2 基準策略（固定權重版）的總報酬拆解成：因子邊際貢獻 + 擇時貢獻 − 成本 + 殘差。這是一個**恆等式**（四項加總保證等於總報酬，見`strategy/attribution.py` 的推導註解），不是四個獨立估計湊出來的近似值。

完整版（固定權重＋擇時）淨總報酬：**+68.7%**（毛報酬 +77.0%）

## 1. 各因子邊際貢獻（單因子版回測比較）

| 因子 | 複合權重 | 單因子版毛報酬 | 邊際貢獻（權重×單因子毛報酬）|
|---|---:|---:|---:|
| momentum | 0.34 | +91.3% | +31.0% |
| value | 0.18 | +66.1% | +11.9% |
| rev_yoy | 0.18 | +36.1% | +6.5% |
| low_vol | 0.30 | +33.0% | +9.9% |
| **合計** |  |  | **+59.3%** |

## 2. 分解結果

| 項目 | 數值 |
|---|---:|
| Σ 各因子邊際貢獻 | +59.3% |
| 擇時貢獻（完整版毛報酬 − 無擇時版毛報酬） | +27.7% |
| − 成本（毛報酬 − 淨報酬） | -8.3% |
| 殘差（無擇時版毛報酬 − Σ因子邊際貢獻，來自緩衝區/inertia等非線性效果） | -10.0% |
| **重建總報酬（應等於完整版淨報酬）** | **+68.7%** |
| 完整版實際淨報酬 | +68.7% |
| 恆等式檢查 | ✅ 通過（兩者一致） |

## 白話解讀

貢獻最大的因子是 **momentum**（+31.0%），貢獻最小的是 **rev_yoy**（+6.5%）。擇時（大盤 60 日均線二元開關）對總報酬的貢獻是 +27.7%，成本總共拖累了 8.3% 個百分點。殘差 -10.0% 反映的是「把因子分數線性加權合成後再統一排名選股」跟「單獨用每個因子各自選股、事後加權平均報酬」之間的差異——正殘差代表因子組合在一起選股比單獨用有加分效果（因子之間有互補性），負殘差則相反。
