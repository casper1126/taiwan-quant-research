# 研究發現：2023-24 健康分數偏低，是市場廣度與大盤指數背離，不是系統缺陷

**日期**：2026-08-19
**相關**：Task 3 機制偵測模組，[docs/DECISIONS.md](../docs/DECISIONS.md)

## 現象

Task 3 驗收標準要求「2023-24 多頭（BULL）比例 > 60%」，但用真實資料跑出來
的結果只有 14.8-23.9%（依健康分數版本不同而異，見下方對照）。

## 排查過程

1. 確認 `health_score.py` 六個成分（波動、寬度、高低差、相關性、不對稱性、
   融資緊縮）的計算邏輯本身沒有錯誤——`margin_squeeze_ratio` 跟 Task 2
   的規格範例對過、其餘指標都有單元測試驗證定義正確。
2. 檢查 2023-2024 這六個成分的實際數值：`breadth`（站上 60 日均線比例）
   平均只有約 0.52，`hl_diff`（創新高減創新低）平均約 0.019，接近中性，
   跟 TAIEX 指數這兩年大漲的走勢明顯不同調。
3. 曾嘗試加入第 7 項「大盤價格 vs 200 日均線」趨勢指標（參考 Kritzman,
   Page & Turkington 2012 的機制模型設計，同時納入趨勢與風險兩類指標），
   結果 2023-24 BULL 比例只從 18.9% 改善到 23.9%，沒有達到「合理提升
   （例如超過 35-40%）」的採用門檻，判定為不夠顯著的改善，回退到原始
   六項成分設計（見 `regime/health_score.py` 內的完整記錄）。

## 結論

2023-24 台股雖然指數大漲，但漲勢集中在台積電等少數權值股，多數個股並沒有
同步走強——這是台股市場結構的真實現象（「權值股領漲、中小型股落後」），
不是本系統的計算錯誤。用市場廣度／微結構型指標建構的健康分數，如實反映了
這個背離：指數創新高的同時，健康分數大部分時間落在 30-50 分之間（中性
偏弱），沒有進入「BULL」門檻要求的 60 分以上。

加上 2024 年確實發生過兩次真實的劇烈修正（4 月地震後修正、8 月全球
carry trade 平倉閃崩），系統正確地把這兩段標記為 BEAR，進一步壓低了
2023-24 整體的 BULL 比例。

## 為什麼不強行調整權重去湊過驗收

任務書把健康分數的六個成分權重寫死（波動18/寬度22/高低差13/相關性13/
不對稱13/squeeze12），這些數字不是我自己選的可調參數。刻意調整這些權重、
或調整分類門檻，只為了讓 2023-24 的 BULL 比例數字好看，等於是重演 Task 2
已經避免過的「調參數硬湊結果」問題（`inst_flow`／`margin_usage` 因子
IC 偏低那次的教訓）。加入趨勢指標是一次誠實的嘗試性修正，測過沒有達到
預設的採用門檻就老實回退，而不是繼續調整直到「看起來過關」為止。

## 後續

- 如果 Task 3 收尾的「線 A」資料範圍延伸執行（見
  `docs/DATA_AVAILABILITY.md`），可以解決 2016-17 完全無資料的問題，
  但不會改變 2023-24 這個「廣度背離」現象本身——這是市場結構特性，
  跟資料起始日無關。
- 這個發現本身可以放進 README 的 Limitations／Findings 章節：市場廣度型
  健康分數在權值股集中領漲的市場下，天生會比單純看大盤指數更保守，
  這是設計取捨（避免被少數大型股的漲幅誤導成整體市場健康），不是必須
  修復的缺陷。
